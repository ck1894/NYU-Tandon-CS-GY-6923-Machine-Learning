This repository contains coursework and applied experiments from **CS-GY 6923: Machine Learning** at NYU Tandon.

The course progresses from statistical learning foundations to modern deep learning and ensemble methods, with an emphasis on mathematical derivations, optimization theory, and implementation from scratch.

---

## Topics Covered

### Foundations of Machine Learning
- Supervised learning: regression & classification  
- Linear models and logistic regression  
- Generalization, model selection, underfitting/overfitting  
- Regularization and empirical risk minimization  

### Optimization
- Gradient descent (SGD, Momentum, Adam)  
- Non-convex loss landscapes  
- Optimization dynamics  

### Neural Networks
- Backpropagation and autograd  
- Depth, initialization, activation functions  
- Normalization and residual connections  

### Modern Architectures
- Convolutional networks and ResNets  
- Sequence modeling (RNNs)  
- Transformers and language model pretraining  

### Ensemble & Classical Methods
- Decision trees and boosting  
- Random forests and deep ensembles  
- KNN and dimensionality reduction  
- Uncertainty in machine learning
  
---

## Tools Used

- **Python** – Primary programming language  
- **NumPy** – Vectorized numerical computation  
- **PyTorch** – Neural network modeling, autograd, and optimization  
- **torchvision** – Image datasets and transforms for CNN experiments  
- **scikit-learn** – Classical ML models (KNN, trees, logistic regression), dimensionality reduction (t-SNE), and evaluation  
- **Matplotlib** – Visualization of loss curves, decision boundaries, embeddings, and model behavior  
- **Pandas** – Data handling and preprocessing  
- **Jupyter Notebooks / Google Colab** – Interactive experimentation and prototyping
